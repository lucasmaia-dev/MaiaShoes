De backend/, execute npm run build e npm run catalog:preview. Confira o plano antes de usar npm run catalog:import. A simulação não altera o banco. A aplicação usa transação e códigos únicos; repetir o lote não duplica produtos nem altera updatedAt dos itens iguais. O comando não apaga cadastros.
